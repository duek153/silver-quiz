# מי רוצה להיות מיליונר? מהדורת חתונת הכסף

משחק חד פעמי לשלומי ואביבה. אתר סטטי: אין שרת ואין התקנות.

## הפעלה
לחיצה כפולה על `index.html`. מומלץ Chrome או Edge, במסך מלא (F11).

## עריכה: `data/game-data.js`
זה הקובץ היחיד שצריך לגעת בו.

- **שאלות** – `questions`. בכל שאלה `correct` הוא מספר התשובה הנכונה: 0=א, 1=ב, 2=ג, 3=ד.
- **תמונות פתיחה** – שמים קבצים ב-`images/intro/` ומוסיפים ל-`introPhotos`, למשל:
  `introPhotos: ["images/intro/1.jpg", "images/intro/2.jpg"],`
- **ברכה** – `greeting.text` (אפשר לרדת שורה עם `\n`), ותמונות ב-`greeting.photos` מתוך `images/greeting/`.
- **כרטיס הטיסה** – `ticket`.

אחרי כל שינוי שומרים ומרעננים את הדף (F5).

## צלילים
הכל נוצר בקוד. להחלפה בקובץ משלכם ראו `sounds/README.txt`.

## העלאה לאחסון חינמי
- **Netlify Drop** (הכי פשוט): נכנסים ל-https://app.netlify.com/drop וגוררים את כל התיקייה. מקבלים קישור מיד.
- **GitHub Pages**: מעלים את התיקייה למאגר, ואז Settings → Pages → Deploy from branch → main.

שימו לב: כל מי שיש לו את הקישור יראה את השמות והתמונות. אפשר גם פשוט להריץ מהמחשב בלי להעלות.

## בזמן המשחק
- כפתור ההשתקה נמצא בפינה הימנית העליונה.
- טעות לא מפסידה: המסך מהבהב באדום ומנסים שוב את אותה שאלה.
- "משחק חדש" בסוף מאפס הכל.
